# Фигура v2 (веб-практика и эмулятор)

- Модель: Quaternius «Universal Base Characters» (Regular Female / Regular Male, CC0), текстуры уменьшены до 1024.
- Позы: `poses.json` — мировые повороты 17 звеньев марионетки атласа для каждой позы приложения
  (`export_poses.py` выгружает их из прежнего решателя, плюс опоры `k` и форма кистей `h`).
- `fig2.mjs` — движок: переходы в суставном пространстве (шарниры колен и локтей, позвоночник дугой по 3 позвонкам,
  большой мах плеча/бедра через «вперёд», очерёдность ноги → корпус → руки → голова), неподвижная опора,
  тело всегда на полу, шаги и постановка ладоней дугой и по очереди, новая опора ставится раньше снятия старой.
- `main.mjs` — мост `window.Mudrya` (go, setTheme, resetView, setYaw, has, setFigure) — тот же интерфейс, что у старого эмулятора.

Сборка: `npm i three@0.170.0 esbuild` и `npx esbuild main.mjs --bundle --format=iife --minify --outfile=figure.js`.
